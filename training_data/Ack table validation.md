# Ack table validation

MNote: 

Hoover table will export event by callback, but hoover model export event according to index.

Ad ack: hoover++ will export event by ad\_id and ad\_replica\_id. 

Slot ack: hoover++ export when callback has slotId.

Request ack: No limitation


Hoover++ Ack table sql validation:

For slot\_ack, no need to explore another index for ad which will cause data duplication. See pr for fix.

 <https://github.freewheel.tv/data/hoover-model/pull/366/files>


Data validation:

Using one hour data to do the validation, filter as below:

```
Hoover:
bitwise_and(request__bit_flags, 576460752303423488) > 0 -- is sampled
 and request__timestamp >= TIMESTAMP '2026-05-29 03:00:00' 
  and request__timestamp <  TIMESTAMP '2026-05-29 04:00:00'
  
Hoover++:
CAST(from_unixtime(request__timestamp) AS timestamp) >= TIMESTAMP '2026-05-29 03:00:00' 
  and CAST(from_unixtime(request__timestamp) AS timestamp) <  TIMESTAMP '2026-05-29 04:00:00'
```

Note: when processing with ad\_ack, need to add following filter:

```
and advertisement__ad_id is not null 
and advertisement__ad_replica_id is not null
```
